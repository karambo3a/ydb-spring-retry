# SLO Workload CLI

A load-generation tool that drives read/write traffic against a YDB table and pushes metrics to Prometheus via OpenTelemetry OTLP. Used to measure SDK reliability under cluster-level fault injection.

## Build

```bash
cd slo
mvn package -DskipTests
```

The executable JAR is produced at `target/ydb-slo-workload-1.0.0-SNAPSHOT-exec.jar`.

## Commands

### `create` — Create the test table

```
java -jar <JAR> create <endpoint> <database> [options]
```

| Argument / Option | Default | Description |
|---|---|---|
| `<endpoint>` | — | YDB endpoint, e.g. `grpc://localhost:2136` |
| `<database>` | — | YDB database path, e.g. `/Root/testdb` |

The table is created with auto-partitioning enabled (min 6, max 1000 partitions) and seeded with 1000 initial rows.

**Example:**

```bash
java -jar $JAR create grpc://localhost:2136 /Root/testdb
```

### `cleanup` — Drop the test table

```
java -jar <JAR> cleanup <endpoint> <database>
```

| Argument | Default | Description |
|---|---|---|
| `<endpoint>` | — | YDB endpoint |
| `<database>` | — | YDB database path |

### `run` — Execute the workload

```
java -jar <JAR> run <endpoint> <database> [options]
```

| Argument / Option | Default | Description |
|---|---|---|
| `<endpoint>` | — | YDB endpoint |
| `<database>` | — | YDB database path |
| `--otlp-endpoint` | **(required)** | OpenTelemetry OTLP endpoint URL, e.g. `http://localhost:9090/api/v1/otlp/v1/metrics` |
| `--report-period` | `250` | Metrics export interval (ms) |
| `--read-rps` | **(required)** | Target read requests per second |
| `--read-timeout` | `10000` | Read timeout (ms) |
| `--write-rps` | **(required)** | Target write requests per second |
| `--write-timeout` | `10000` | Write timeout (ms) |
| `--time` | **(required)** | Total run duration (seconds) |

**Example:**

```bash
java -jar $JAR run grpc://localhost:2136 /Root/testdb \
  --otlp-endpoint http://localhost:9090/api/v1/otlp/v1/metrics \
  --read-rps 1000 --write-rps 100 --time 600
```

## Table Schema

```sql
CREATE TABLE slo_test_table (
    id                Int64,
    hash              Int64,    -- SHA-1 based numeric hash of id
    payload_str       Text,
    payload_double    Double,
    payload_timestamp Timestamp,
    payload_hash      Int64,
    PRIMARY KEY (hash, id)
);
```

## What the Workload Does

Two concurrent jobs run simultaneously (10 workers each, 20 threads total):

- **`readJob`** — reads rows by random IDs (keys generated by `writeJob`)
- **`writeJob`** — generates and upserts new rows

Rate limiting is done via a semaphore-based token bucket with a 100ms refill window.

## Collected Metrics (pushed to Prometheus via OTLP)

| Metric | Type | Description |
|---|---|---|
| `sdk.operations.total` | Counter | Total number of operations by type |
| `sdk.operations.success.total` | Counter | Successful operations |
| `sdk.operation.latency.seconds` | Histogram | Operation latency in seconds |
| `sdk.pending.operations` | UpDownCounter | In-flight operations |

Labels: `ref`, `operation_type`, `sdk`, `sdk_version`, `workload`, `operation_status`

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `REF` | `unknown` | Git ref label (used in metrics) |
| `WORKLOAD` | `java-jdbc` | Workload name label (used in metrics) |

## Authentication

The workload uses **anonymous credentials** by default (suitable for a local YDB instance).

## Retry Configuration

Retry behavior is configured in `src/main/resources/application.properties`:

| Property | Default | Description |
|---|---|---|
| `ydb.transaction.retry.enabled` | `true` | Enable/disable retry |
| `ydb.transaction.retry.max-retries` | `10` | Maximum retry attempts |
| `ydb.transaction.retry.slow-backoff-base-ms` | `50` | Slow backoff base (ms) |
| `ydb.transaction.retry.fast-backoff-base-ms` | `5` | Fast backoff base (ms) |
| `ydb.transaction.retry.slow-cap-backoff-ms` | `5000` | Slow backoff cap (ms) |
| `ydb.transaction.retry.fast-cap-backoff-ms` | `500` | Fast backoff cap (ms) |
| `ydb.transaction.retry.idempotent` | `true` | Treat operations as idempotent |
